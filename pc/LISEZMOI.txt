GÉNÉRATEUR DE RECETTES — version {VERSION}
=========================================

Carnet de recettes personnel : importe des recettes (Marmiton, 750g, Cuisine AZ, Ricardo…
et des PDF de fiches eFarmz), filtre selon ce que tu as dans le frigo, tire une recette au sort
et prépare ta liste de courses. Tout reste sur ton ordinateur.

1) Décompresser ce dossier où tu veux (par exemple dans Documents), puis le lancer
   - Windows : double-clic sur  lancer-recettes.bat
               Au premier lancement, si Python n'est pas installé, le lanceur propose de l'installer
               (réponds O ou Y), puis installe l'extraction de PDF. Les fois suivantes, il démarre
               directement l'appli. Si l'installation automatique échoue :
               https://www.python.org/downloads/  (3.9 ou plus récent, coche « Add python.exe to PATH »).
   - macOS   : installe d'abord Python 3 (https://www.python.org/downloads/), puis double-clic sur
               lancer-recettes.command
               (si macOS refuse : clic droit > Ouvrir, ou dans le Terminal : chmod +x *.command *.sh)
   - Linux   : Python 3 est en général déjà installé. Lance : ./lancer-recettes.sh

   Le navigateur s'ouvre sur http://localhost:8765 . Pour arrêter : ferme la fenêtre noire (ou Ctrl+C).

2) Windows : si la fenêtre indique que Python est installé mais introuvable, ferme-la et relance le lanceur.

3) Utiliser
   - « Importer » : cherche sur un site ou colle l'adresse d'une recette.
   - Tes recettes sont enregistrées dans recettes.json, à côté de ces fichiers.
     Garde ce fichier pour sauvegarder ou déplacer ta base.

PDF eFarmz (facultatif)
   Sous Windows, l'extraction de PDF est installée par le lanceur. Ailleurs :   pip install pdfplumber
   Dépose tes fiches PDF dans le dossier  eFarmz/  puis, dans « Importer », choisis « eFarmz (PDF) ».

Mettre à jour
   Avec lancer-recettes.bat / .sh / .command : rien à faire, la dernière version est téléchargée au lancement
   (serveur, page et module PDF ; ton fichier recettes.json n'est pas touché). Pour la forcer à la main :
   python serveur_recettes.py --maj
   Avec recettes.exe : télécharge le nouveau .exe sur
   https://github.com/pmeyssonnier/generator-recipes/releases

Respect des sites : usage personnel, avec pauses entre les requêtes (voir le README du projet).
